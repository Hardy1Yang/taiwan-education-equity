# 教育的距離｜臺灣教育機會觀測

**[開啟互動網站](https://hardy1yang.github.io/taiwan-education-equity/)**

104–114學年度（2015–2025起始年），比較臺灣偏遠與非偏遠公立國中小的學生、專任教師、班級與學校規模。11期觀測，首末相隔十年。

- 十年趨勢：學制、縣市、8項指標，以及逐年／固定起始群組比較。
- 縣市探索：偏遠學校占比地圖、資源比較與114學年度校別查詢。
- PISA 2022：OECD官方臺灣彙總；個體資料尚未取得，未估計城鄉或背景調整差距。
- [研究報告](data/analysis.md)、[研究方法](data/methods.md)、[來源清單](data/manifest.json)、[整合資料下載](data/education-equity-data.zip)。

資料快照：dd36035f37f1。教育部資料39,878個唯一校年，36,440筆符合公立本校主分析條件。

偏遠國小學生數十年間減少24.9%，偏遠國中減少46.0%。較低學生／教師比不能等同師資品質改善；固定群組比較協助檢查分類與校碼進出影響。PISA社經分組差距不等於行政偏遠或城鄉差距。

來源：教育部[國小校別資料](https://data.gov.tw/dataset/6240)、[國中校別資料](https://data.gov.tw/dataset/6239)、[偏遠名錄](https://data.gov.tw/dataset/28582)、OECD PISA 2022臺灣報告（各圖附頁碼），縣市底圖重用既有NLSC共用界圖。
